# MoodLens 使用演示

线上地址：https://askjdghfjkghashjkasd.github.io/C6-ai-mood-journal/

## 演示脚本

1. 打开链接，顶部徽标从「AI 模型加载中」变为「AI 模型就绪 ✓」（首次约需下载模型，之后走缓存）。
2. 在「写下此刻」输入一段文字，例如：
   `今天第一次独立跑通了整个项目，虽然 debug 了很久，但终于成功，特别有成就感。`
3. 点「✨ AI 情绪分析」→ 显示情绪标签（积极）+ 置信度百分比 + 一条反思提示。
4. 点「保存日记」→ 看板刷新：日记数、主导情绪、情绪趋势折线、分布条形、历史列表。
5. 再写一条偏负面的文字并保存，观察趋势折线下降、分布图变化、主导情绪改变。
6. 点「导出」下载 JSON 备份；点「导入」恢复备份；点「清空」重置。

## 预期结果

- 中文 / English 均可正确分类为 积极 / 中性 / 消极；
- 全程本地推理，无任何文字上传网络；
- 关闭页面后数据仍在（localStorage），换浏览器则数据各自独立。
